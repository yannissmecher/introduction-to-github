# Programming with Visual Studio Code

This guide will help you get started with programming using Visual Studio Code and GitHub.

## What You'll Need

1. **Visual Studio Code** - Download from [code.visualstudio.com](https://code.visualstudio.com/)
2. **Python** - Download from [python.org](https://www.python.org/) (version 3.7 or higher)
3. **Git** - Download from [git-scm.com](https://git-scm.com/)

## Getting Started

### Step 1: Clone This Repository

Open Visual Studio Code and press `Ctrl+Shift+P` (Windows/Linux) or `Cmd+Shift+P` (Mac) to open the Command Palette.

Type "Git: Clone" and paste this repository URL.

### Step 2: Open the Project

Once cloned, VS Code will ask if you want to open the repository. Click "Open".

### Step 3: Install Python Extension

1. Click on the Extensions icon in the sidebar (or press `Ctrl+Shift+X`)
2. Search for "Python"
3. Install the official Python extension by Microsoft

### Step 4: Run the Example Program

1. Open the file `hello.py`
2. Press `F5` to run the program with debugging, or
3. Right-click in the editor and select "Run Python File in Terminal"

## Learning More

### Visual Studio Code Features

- **IntelliSense**: Code completion and suggestions as you type
- **Debugging**: Set breakpoints and step through your code
- **Terminal**: Built-in terminal for running commands
- **Source Control**: Manage your Git commits right in VS Code

### Keyboard Shortcuts

- `Ctrl+` ` `: Toggle terminal
- `F5`: Start debugging
- `Ctrl+Shift+P`: Command palette
- `Ctrl+P`: Quick file open
- `Ctrl+/`: Toggle line comment
